## AI가 참고할 순서

1. DKB의 공통·조직·프로젝트 규칙을 확인합니다.
2. 이 프로젝트의 화면 정의서와 `ui-specs/manifest.json`을 읽고 관련 Screen ID를 확인합니다.
3. `ui-specs/elements.json`의 원본 경로·Git 기준·SHA와 현재 소스를 대조합니다.
4. 프로젝트 요소를 우선 재사용하고 [공통 요소와 업무 패턴](/admin/storybook/)은 별도 참고합니다. 회사 비공개 코드·자산을 개인 공통 요소로 복사하지 않습니다.
5. 정상·빈 상태·오류·긴 문구·키보드·좁은 화면을 검수합니다. Story의 합성 자료를 승인된 업무 요구사항으로 간주하지 않습니다.

원본 UI 명세와 기존 Story ID는 그대로 보존했습니다. 새 항목만 `요소/` 아래에서 관리하며 기존 전체 화면의 등록 상태를 완료로 승격하지 않습니다.
