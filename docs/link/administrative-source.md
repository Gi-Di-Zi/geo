# 행정동 코드·법정동 관할 관계 자료

확인일: 2026-10-30. 행정동코드는 PNU에서 잘라내는 법정동코드와 다른 체계다. 화면은 PNU·법정동코드, 행정동코드, 주소를 구분하며 행정동을 단순 접두어로 추정하지 않는다.

원문 파일은 다음과 같이 역할이 다르다.

- `KIKcd_H.20261012.xlsx`: 행정동코드, 시도명, 시군구명, 읍면동명, 생성일자, 말소일자.
- `KIKcd_B.20261012.xlsx`: 같은 배포 시점의 법정동코드와 명칭.
- `KIKmix.20261012.xlsx`: 행정동코드와 관할 법정동코드의 실제 관계.

이 자료의 **행안부 주민등록 행정동코드는 10자리 문자열**이다. 예를 들어 청운효자동은 `1111051500`이다. 행정기관 자체의 7자리 기관코드나 통계청 코드와 섞지 않는다. 자릿수가 비슷하다는 이유로 다른 체계의 값을 0으로 패딩하지 않는다.

## 대응 관계와 확인 범위

`KIKmix`에 있는 정확한 법정동코드·행정동코드 관계만 사용한다. 법정동 하나에 대응하는 행정동이 여러 개면 모두 후보로 유지한다. 해당 법정동을 입력했다는 사실만으로 개별 토지의 행정동을 확정하지 않는다. 행정동코드만으로 토지 지번이나 PNU를 만들지 않는다.

원문의 7개 출장소 자기참조 행은 법정동 열에 행정코드가 그대로 들어 있고 같은 배포본의 법정동 사전에는 등록되어 있지 않다. 이 행은 `verified: false`로 보존하되 변환 후보에서는 제외한다. 나머지 관계는 `verified: true`다. 원문을 조용히 버리거나 자기참조를 가짜 법정동 관계로 사용하는 일을 피한다.

관할 법정동 명칭은 같은 ZIP의 `KIKcd_B`에서 읽는다. 별도로 운용 중인 code.go.kr 사전과는 원천·기준일·버전이 다르다. 두 자료의 현재 상태나 과거 명칭을 같은 시점이라고 가정하지 않는다. 개별 관할 경계·필지·도로명주소·주민센터 위치·통계청 코드 대응은 확보하지 않았다.

## 저장·갱신·검증

기본 저장 경로는 `.data/reference/link/administrative/`이며 `LINK_ADMINISTRATIVE_DIR`로 변경한다. Git 제외 영속 영역이고 사용자 임시 작업과 분리한다. 버전 디렉터리에는 원문 ZIP, 정규화 snapshot, 체크섬·출처·기준일 manifest를 보존한다. 이동·삭제 없이 활성화 이력을 먼저 기록하고 포인터를 갱신한다. 포인터 기록 중단 시 마지막 정상 활성화 이력으로 복구한다. 이미 확정된 버전은 덮어쓰지 않는다. 정규화 규칙을 보완한 경우에는 같은 원문도 새 버전으로 저장한다.

부모는 전체 명칭 경로를 우선한다. 동일 전체명을 쓰는 시도·시군구와 시도명 열에 출장소명만 있는 예외는 코드 구성의 실제 등록 상위 코드를 확인한다. 특정 시·구·출장소의 이름과 코드를 하드코딩하지 않는다.

```powershell
npm.cmd run link:administrative
npm.cmd run link:administrative -- --status
# 같은 날 다시 확인할 때
npm.cmd run link:administrative -- --force
# 운영자가 확보한 공식 ZIP을 검증할 때
npm.cmd run link:administrative -- --import C:\reference\jscode20261012.zip
```

매일 새 게시물이 나왔는지 확인할 수 있지만 원천 자체가 매일 발행된다고 표현하지 않는다. 한국 시간 기준 당일 확인 기록을 영속 저장하고 동시 요청을 공유한다. `/link/reference`의 공통 갱신은 모든 사용자가 같은 기록을 사용하며 당일 재적용을 막는다. 동일 원문은 활성화 이력을 추가하지 않고 확인 시각만 갱신한다. 실패·중단 시 이전 정상 버전을 유지하고 화면에서는 5분 뒤 실패한 원천만 재확인할 수 있다. `--force`는 운영자용 CLI에만 있다. 운영 자동 스케줄은 설치하지 않았다.

공식 호스트의 게시판·다운로드 경로만 사용하며 리다이렉트를 따라가지 않는다. 다운로드 10MiB, 외부 ZIP 항목 50개·압축 해제 합계 40MiB 상한, ZIP 경로·로컬/중앙 항목·CRC·필수 파일·XLSX 문자형·필수 열·코드 중복·부모 순환·관계 등록·전국 규모·기존 코드 급감을 검사한다. ZIP을 경로에 풀거나 수식·외부 링크를 실행하지 않는다.

## 이용조건·검증 상태

[행정안전부 저작권정책](https://www.mois.go.kr/frt/sub/a08/copyrightPolicy/screen.do)은 자유이용 시 출처 표시를 요구하고, 공공누리 표시가 없는 자료는 담당자와 사전 협의하도록 안내한다. 해당 게시물에서 개별 공공누리 표시는 확인하지 못했다. 공개 원문은 로컬 개발·검증용으로 확보했으며, **공개 재배포 조건을 확정했다고 보고하지 않는다**. 공개 운영 전 자료의 적용 조건을 제공기관에 확인해야 한다.

`node --test tests/link/administrative.test.ts` 6개 검사가 통과했다. 원문 스키마·문자형 코드·기관코드 혼동 방지·복수 관계·미확인 자기참조 제외·부모 순환·동일 전체명/출장소 계층·ZIP 손상·전국 활성화·실패 유지·포인터 중단 복구·한국 날짜의 재확인 제한을 검사한다. 합성 전국 규모 테스트 자료는 `.data/link-tests/administrative/<임의 ID>/`에 격리하며 운영 전국 자료로 노출하지 않는다. 실제 공식 ZIP 수집·활성화와 합성 fixture 검증을 구분한다.
